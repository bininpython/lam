# Lamacon Showroom

Catálogo institucional da Lamacon Materiais de Construção, desenvolvido com React, TypeScript e Vite.

## Tecnologias

- React 18 + TypeScript
- Vite 6
- Lucide React
- CSS responsivo, sem dependência de framework visual

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

O build de produção é gerado em `dist/`. O showroom apresenta a empresa, opções de atendimento, localização e uma lista de orçamento preparada para integração com o WhatsApp comercial.
